## Product Roadmap

Here's what we're working on and what's coming next for Shopigent Returns. This is a living document — priorities shift based on merchant feedback, so check back regularly.

### 🚀 Recently Shipped

- **AI Agent v1** — MCP-powered agent analyzes, approves, denies, and refunds returns automatically
- **Policy Engine** — Configurable rules with time windows, amount limits, restocking fees, and auto-approve
- **Customer Portal** — Self-service return initiation at `/return`
- **Fraud Detection** — IP checks, velocity analysis, amount anomalies
- **Auto-Refund** — Direct Shopify refund execution via Admin API
- **Label Generation** — SendCloud, Shippo, and EasyPost integration
- **Email Notifications** — Automated emails on approve/deny/refund
- **Analytics Dashboard** — Return rate, auto-resolution %, trends, top reasons
- **Documentation Site** — Full docs with guides, changelog, and blog

### 🔜 In Progress (Next 30 Days)

- **Exchange Workflow** — Let customers choose exchanges instead of refunds, with automated inventory handling
- **SMS Notifications** — Pro plan SMS alerts for high-priority events
- **Multi-store Support** — Enterprise plan for merchants running multiple Shopify stores
- **Improved Analytics** — Charts, exportable reports, fraud savings calculator

### 📋 Planned (Next 90 Days)

- **Deep Return Reason Analytics** — Understand why customers return with AI-powered reason categorization
- **Partial Refund Automation** — AI agent decides refund amounts based on item condition and policy
- **RMA Number Generation** — Custom RMA number format for each store
- **Return Window Reminders** — Automated email/SMS reminders before the return window closes
- **Shopify Flow Integration** — Connect returns workflow to Shopify Flow for custom automations
- **Bulk Actions** — Select and approve/deny multiple returns at once

### 💡 Under Consideration

- **Returns Portal White-label** — Custom domain, branded emails, and portal theming
- **Print-at-home Labels** — Direct thermal label printing from the dashboard
- **International Returns** — Multi-currency, cross-border return shipping
- **Restocking Automation** — Auto-restock returned items via Shopify inventory API
- **Returns Insurance** — Integrated shipping insurance for high-value returns
- **Public API** — REST API for integrating returns into custom workflows

### 📬 Have a Suggestion?

We build based on merchant feedback. If there's something you'd like to see on the roadmap, [let us know](mailto:shopigent@greeknous.com).
