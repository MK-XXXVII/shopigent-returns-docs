## About Shopigent Returns

### The Problem

Returns are expensive. The average merchant spends 10+ hours per week manually processing them — checking policies, approving or denying, issuing refunds, generating labels, and watching for fraud. It's unglamorous, repetitive, and eats into the time you'd rather spend growing your business.

### The Solution

Shopigent Returns is an AI-powered return management system for Shopify. We built an MCP-driven AI agent that handles the entire return lifecycle — from customer intake to policy evaluation, fraud detection, refund execution, and label generation — without you lifting a finger.

Deploy once, configure your policies, and let the agent work.

### Built by Greek Nous

Shopigent Returns is a product of **Greek Nous** — a solo development studio focused on building practical, AI-native tools for ecommerce.

Every line of code, every design decision, and every deployment is done by a single developer who believes that the best software is simple, focused, and solves one thing well.

### Our Philosophy

- **AI that acts, not just chats** — Agents should do the work, not just suggest what to do
- **Open standards** — MCP protocol means you're not locked into a platform; bring your own AI client
- **Self-hosted by default** — Your data stays in your Railway Postgres, under your control
- **Privacy-first** — No data selling, no ad tracking, no third-party model training

### Tech Stack

| Component | Technology |
|---|---|
| App Framework | Remix + Polaris |
| Backend | Express + Prisma |
| Database | Postgres |
| AI Interface | MCP (Model Context Protocol) |
| Deploy | Railway |
| Labels | SendCloud, Shippo, EasyPost |
| Docs | Headless Express + Markdown |
